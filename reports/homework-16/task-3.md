# Пункт 3. Порядок элементов класса и модификаторы

## Что сделано

В компонентах и классе `Collection` явно указаны модификаторы свойств и методов.
В `AppComponent` методы сохранения даты и числа посещений перенесены в конец класса,
после методов жизненного цикла и публичного `isPrimaryColor`.

Для этого проекта принят порядок:

1. Свойства: публичные, затем используемые шаблоном, затем внутренние.
2. Конструктор, если он нужен.
3. Методы жизненного цикла: `ngOnInit`, `ngOnDestroy`.
4. Публичные методы.
5. Методы, которые вызывает шаблон.
6. Внутренние приватные методы.

Это соглашение для удобства чтения. TypeScript не требует именно такого порядка.

## Что означают модификаторы

| Модификатор | Для чего используется |
| --- | --- |
| `public` | К свойству или методу разрешено обращаться снаружи класса |
| `protected` | Доступ есть внутри класса, у его наследников и в Angular-шаблоне компонента |
| `private` | Часть внутренней реализации класса |
| `readonly` | Свойству нельзя присвоить другое значение после инициализации |

Примеры из проекта:

```ts
protected readonly companyName = 'РУМТИБЕТ';
protected clickCount = 0;
private timerId: number | undefined;
```

Название компании читается шаблоном и не меняется, поэтому у него `protected readonly`.
Счётчик меняется при кликах, поэтому `readonly` у него нет.
Идентификатор интервала нужен только самому компоненту, поэтому он `private`.

Методы `increaseCount`, `decreaseCount` и `toggleWidget` вызываются шаблоном и имеют
`protected`. Методы `ngOnInit` и `ngOnDestroy` объявлены `public`: они реализуют
интерфейсы жизненного цикла Angular.

В `Collection` методы `getAll`, `get`, `clear`, `remove`, `replace` объявлены `public`,
потому что другой код должен вызывать их через объект коллекции. Массив `items` остаётся
`private`, чтобы работать с ним через эти методы.

`numberCollection`, `colorCollection` и `advantages` получили `readonly`.
Это запрещает заменять само свойство, но не замораживает объект или массив.
Например, `numberCollection.clear()` по-прежнему работает.

У обычного конструктора оставлена запись `constructor()`: без модификатора он публичный.
В интерфейсе `Advantage` модификаторы доступа не добавляются: его поля описывают форму объекта.
К свободным функциям в `training.ts` модификаторы доступа классов также неприменимы.

Тип `void` у методов означает, что они выполняют действие без возвращаемого результата.
`number | undefined` означает: идентификатор таймера либо уже создан, либо пока отсутствует.

Модификаторы TypeScript проверяют код при разработке. `protected` и `private` в таком
виде не являются защитой секретов от пользователя браузера.
