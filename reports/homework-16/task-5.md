# Пункт 5. Счётчик кликов

Состояние и методы находятся в `NavbarComponent`.

```ts
protected clickCount = 0;

protected increaseCount(): void {
  this.clickCount += 1;
}

protected decreaseCount(): void {
  if (this.clickCount > 0) {
    this.clickCount -= 1;
  }
}
```

`clickCount` хранит число. Запись `+= 1` увеличивает его на единицу, `-= 1` уменьшает.
Проверка `> 0` не позволяет методу сделать значение отрицательным.

## Как HTML вызывает методы

```html
<button type="button" (click)="increaseCount()">+</button>
<output>{{ clickCount }}</output>
<button type="button" (click)="decreaseCount()" [disabled]="clickCount === 0">−</button>
```

Это сокращённый фрагмент шаблона. `(click)` — привязка события: после клика Angular
вызывает указанный метод. Интерполяция внутри `output` показывает число.
`type="button"` указывает, что кнопка выполняет обычное действие и не отправляет форму.

Когда значение равно нулю, `[disabled]` отключает кнопку уменьшения.
После увеличения до единицы кнопка автоматически становится доступной.

Проверка в методе и `disabled` решают разные задачи: `disabled` ограничивает действие
через интерфейс, а `if` сохраняет правило самого счётчика при вызове метода.

Отключённая кнопка имеет приглушённый цвет и курсор `not-allowed`.
В полном шаблоне у кнопок есть `aria-label`, объясняющий назначение символов,
а у `output` — `aria-live="polite"` для объявления изменений вспомогательными технологиями.

Счётчик хранится в памяти компонента. Переключение на дату не сбрасывает его,
полная перезагрузка страницы создаёт новый компонент с нулевым значением.
