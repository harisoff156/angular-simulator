## Где находится код

| Компонент | Задания |
| --- | --- |
| `src/app/hero/hero.component.*` | Поля поиска, состояние кнопки, live-input |
| `src/app/navbar/navbar.component.*` | Дата, счётчик, переключатель |
| `src/app/app.component.*` | Экран загрузки и показ страницы |
| `src/collection.ts` | Явные модификаторы методов старого учебного класса |

Здесь используются обычные свойства классов, методы и шаблоны Angular.
Для этого объёма задач достаточно существующих компонентов.

## Как посмотреть

Запусти `npm start -- --host 0.0.0.0` и открой `http://localhost:4200/`.
При полном обновлении страницы сначала на две секунды появляется загрузчик.
Затем справа в шапке видна дата и кнопка переключения на счётчик.
Под формой поиска находится live-input.

Если npm пишет `No active Node.js version is configured`, сначала выбери установленную
версию Node.js в своём nvm. Код приложения к этой ошибке не относится.

Макет для новых элементов:
[homework-16 в Figma](https://www.figma.com/design/vLzZ88XBugSWrBpXBmyItI/homework-16?node-id=0-1).
Виджет размещён справа под консультацией, live-input — под формой поиска.

## Проверка

В Playwright CLI проверены обе стороны привязки, очистка каждого обязательного поля,
обновление даты, увеличение и уменьшение счётчика, запрет отрицательного значения,
переключение с сохранением счётчика и немедленный вывод live-input.
Проверено, что до завершения задержки компоненты страницы не показаны, а после неё
загрузчик исчезает. Проверка загрузки заняла около 2,25 секунды вместе с открытием страницы;
сама задержка в коде — 2000 мс после инициализации Angular.
Сборка проходит. В обоих режимах шапки проверены ширины 1920, 1280, 1024, 768, 390
и 320 px: горизонтальной прокрутки нет, шапка не перекрывает заголовок.

Кнопка поиска в этом задании получает условие доступности. Обработчик поиска туров
заданием не предусмотрен, поэтому отправки запроса на сервер здесь нет.
