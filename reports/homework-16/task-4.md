# Пункт 4. Дата с обновлением каждую секунду

Код находится в `src/app/navbar/navbar.component.ts`, вывод — в его HTML-шаблоне.

## Начальное значение

```ts
protected currentDate = new Date().toLocaleString('ru-RU');
private timerId: number | undefined;
```

`new Date()` создаёт объект с текущей датой и временем.
`toLocaleString('ru-RU')` превращает его в строку с русским форматом даты и временем
до секунд. Часовой пояс берётся из настроек браузера пользователя.
Значение вычисляется сразу, поэтому при показе шапки не приходится ждать первый тик.

## Запуск интервала

```ts
public ngOnInit(): void {
  this.timerId = window.setInterval(() => {
    this.currentDate = new Date().toLocaleString('ru-RU');
  }, 1000);
}
```

`ngOnInit` Angular вызывает один раз при инициализации компонента.
`setInterval` регистрирует функцию, которую браузер вызывает повторно.
`1000` — период в миллисекундах, то есть одна секунда.

Стрелочная функция `() => { ... }` сохраняет `this` компонента. Здесь `this.currentDate`
означает именно свойство `NavbarComponent`.
На каждом тике код заново читает реальное время, поэтому не накапливает ошибку простым
прибавлением одной секунды к старому значению.

В HTML достаточно `{{ currentDate }}`. Angular обновляет текст при изменении свойства.
В проекте уже подключён `provideZoneChangeDetection()`, поэтому обновление из браузерного
таймера участвует в проверке изменений Angular.

## Очистка

```ts
public ngOnDestroy(): void {
  window.clearInterval(this.timerId);
}
```

`setInterval` возвращает числовой идентификатор. Он хранится в `timerId`, чтобы потом
остановить именно этот интервал. `ngOnDestroy` вызывается перед удалением компонента.
Очистка не даёт интервалу продолжать работу после удаления шапки.
Если идентификатора ещё нет, `clearInterval(undefined)` ничего не делает.

Класс объявлен `implements OnInit, OnDestroy`: TypeScript проверяет наличие нужных методов.
Сами интерфейсы не запускают таймер — это делает код внутри `ngOnInit`.
Браузер может реже вызывать таймеры в фоновой вкладке; следующий тик всё равно покажет
актуальное время.
