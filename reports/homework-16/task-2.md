# Пункт 2. Двусторонняя привязка и disabled

## Что сделано

В `src/app/hero/hero.component.ts` добавлены свойства для трёх полей:

```ts
protected location = '';
protected hikeDate = '';
protected participants = '';
```

Пустая строка означает, что значение пока не выбрано. Все три свойства имеют тип `string`:
TypeScript определяет его по начальному значению. Дата от `input type="date"` хранится
как строка вида `2026-10-16`, а не как объект `Date`.

В компонент импортирован `FormsModule` из `@angular/forms` и добавлен в `imports`.
Это подключает директиву `ngModel`, которую использует шаблон.

## Как работает привязка

```html
<select [(ngModel)]="location" required>
  <option value="">Локация для тура</option>
  <option value="алтай">Алтай</option>
</select>
```

Это сокращённый пример из шаблона. `[(ngModel)]` связывает поле со свойством в обе стороны:

1. Пользователь выбирает «Алтай» — в `location` записывается `'алтай'`.
2. Если код изменит `location`, Angular обновит выбранную опцию на странице.

В `[ ]` находится привязка свойства, в `( )` — обработка события.
Сочетание `[( )]` объединяет передачу значения в поле и получение нового значения из поля.
Отдельные обработчики `change` для каждого поля не нужны.

Так же связаны `hikeDate` с датой и `participants` со вторым `select`.
Атрибут `selected` у начальных опций убран: выбором теперь управляет значение свойства.
Начальная опция имеет `value=""`, чтобы она считалась отсутствием выбора.
Атрибут `required` обозначает обязательное поле.

## Когда кнопка отключена

```html
[disabled]="!location || !hikeDate || !participants"
```

`!` — логическое отрицание. Для пустой строки `!location` даёт `true`.
Оператор `||` означает «или»: достаточно одного `true`, чтобы всё условие стало истинным.

Пока хотя бы одно значение пустое, Angular устанавливает свойство `disabled` кнопки в `true`.
Когда заполнены все три поля, условие становится `false`, и кнопка доступна.
Если снова очистить поле, кнопка отключится. Здесь не нужна отдельная переменная для состояния
кнопки: она прямо зависит от трёх значений.

В SCSS добавлен селектор `.hero__search-button:disabled`: серый фон, приглушённый текст
и курсор `not-allowed`. Hover-стили применяются только к `:not(:disabled)`.
Отключение настоящее, через свойство HTML-кнопки; CSS лишь показывает это состояние.
