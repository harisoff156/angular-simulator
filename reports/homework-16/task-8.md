# Пункт 8. Искусственная загрузка страницы

Код находится в корневом `AppComponent`: он решает, показывать загрузчик или всю страницу.

## Начальное состояние и задержка

```ts
protected isLoading = true;
private loadingTimeoutId: number | undefined;

public ngOnInit(): void {
  this.loadingTimeoutId = window.setTimeout(() => {
    this.isLoading = false;
  }, 2000);
}
```

Сначала `isLoading` равно `true`. После инициализации компонента запускается `setTimeout`.
В отличие от `setInterval`, он вызывает функцию один раз.
`2000` миллисекунд — две секунды. После задержки флаг становится `false`.
Это учебная задержка после запуска Angular, она не измеряет реальную загрузку фотографий.

## Переключение HTML

```html
@if (isLoading) {
  <!-- Загрузчик -->
} @else {
  <app-navbar />
  <app-hero />
  <app-about-hike />
  <app-programs />
  <router-outlet />
}
```

Пока флаг истинный, существует только разметка загрузчика. Через две секунды Angular
удаляет её и создаёт компоненты страницы. Именно тогда инициализируется шапка и запускается
её секундный интервал. На полном обновлении страницы задержка повторяется.

Старые вызовы сохранения даты посещения и числа заходов остаются в конструкторе.
Они выполняются один раз при создании `AppComponent`, независимо от задержки.

## Иконка и анимация

Иконка — встроенный SVG с двумя круговыми стрелками, как в примере макета.
SVG описывает линии векторными путями, поэтому отдельная картинка или библиотека не нужны.

У контейнера `position: fixed` и `inset: 0`: он занимает весь экран.
CSS Grid центрирует иконку и подпись. Свойство `animation` задаёт вращение:

```scss
animation: spin 1s linear infinite;

@keyframes spin {
  to {
    transform: rotate(360deg);
  }
}
```

`1s` — полный оборот за секунду, `linear` — постоянная скорость, `infinite` — повторение.
Когда Angular удалит загрузчик из DOM, исчезнет и анимация.
Для настройки `prefers-reduced-motion: reduce` вращение отключено.
`role="status"` и подпись «Загрузка...» сообщают о состоянии страницы.

В `ngOnDestroy` вызывается `window.clearTimeout(this.loadingTimeoutId)`.
Если компонент удалён раньше двух секунд, отложенная функция уже не выполнится.
Хранение идентификатора и очистка используют тот же принцип, что описан в пункте 4.
