# Пункт 6. Переключение даты и счётчика

В `NavbarComponent` добавлено булево свойство и метод:

```ts
protected isTimerVisible = true;

protected toggleWidget(): void {
  this.isTimerVisible = !this.isTimerVisible;
}
```

Тип `boolean` содержит два значения: `true` и `false`.
Оператор `!` меняет их местами. Каждый клик переключает текущее состояние.

## Выбор блока в шаблоне

```html
@if (isTimerVisible) {
  <p class="navbar__date">{{ currentDate }}</p>
} @else {
  <!-- Кнопки счётчика и его значение -->
}
```

Когда условие истинно, Angular создаёт разметку даты. Иначе создаёт разметку счётчика.
Одновременно показан один виджет. Для этого использована встроенная конструкция `@if`.

Удаляется только выбранный фрагмент шаблона. Сам `NavbarComponent` продолжает существовать,
поэтому его `clickCount` сохраняется, а интервал обновления времени продолжает работать.
При возвращении к дате сразу видно актуальное время.

## Текст кнопки

```html
<button type="button" (click)="toggleWidget()">
  {{ isTimerVisible ? 'Показать кликер' : 'Показать дату' }}
</button>
```

Оператор `условие ? первое : второе` называется тернарным.
При `true` он возвращает первую строку, при `false` — вторую.
Подпись обозначает действие следующего клика: когда видна дата, предлагается показать
кликер, а когда виден кликер — дату. Эти подписи взяты из макета.

Отдельное свойство с текстом кнопки не нужно: текст вычисляется из того же состояния,
которое управляет `@if`. Так подпись и показанный виджет не расходятся.
