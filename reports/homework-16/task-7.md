# Пункт 7. Live-input

Поле находится под формой поиска в `src/app/hero/hero.component.html`, как в новом макете.
Состояние хранится в `HeroComponent`:

```ts
protected liveText = '';
```

Разметка:

```html
<div class="hero__live">
  <input type="text" aria-label="Live-input" [(ngModel)]="liveText" />
  <span class="hero__live-result">{{ liveText }}</span>
</div>
```

Когда пользователь вводит или удаляет символы, `ngModel` обновляет `liveText`.
Интерполяция сразу выводит новое значение в соседнем `span`.
Кнопка отправки, событие `blur` и ручное чтение DOM для этого не нужны.

Это тот же механизм двусторонней привязки, что используется в пункте 2.
`FormsModule` уже включён в `imports` этого компонента.
`aria-label` даёт полю понятное имя для вспомогательных технологий без дополнительной
видимой надписи, которой нет в макете.

## Расположение

`display: flex` размещает поле и текст в строку, `gap` задаёт промежуток.
У текста стоит `overflow-wrap: anywhere`, чтобы длинное слово не растягивало страницу.
На узком экране включён перенос: если места рядом не хватает, текст переходит ниже.

Используется обычная интерполяция, поэтому введённая строка отображается как текст.
Например, `<b>Привет</b>` будет показано буквально, а не превратится в HTML-тег.
При очистке поля исчезает и текст рядом.
