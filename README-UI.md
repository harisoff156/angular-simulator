# Как работает шапка и первый блок

Интерактивные задания Homework №16 описаны отдельно:
[отчёты по пунктам 2–8](reports/homework-16/README.md).
Теперь поля связаны с данными, кнопка поиска зависит от заполнения, в шапке есть
дата и счётчик, а под формой — live-input. При обновлении страницы показывается загрузчик.

## Из каких частей состоит страница

`AppComponent` — главный компонент. В его HTML находятся четыре компонента:

- `<app-navbar />` — шапка сайта;
- `<app-hero />` — первый большой блок с заголовком и формой.
- `<app-about-hike />` — фотографии и описание похода;
- `<app-programs />` — преимущества программ и фотоколлаж.

Описание двух новых блоков, цикла `@for` и исправлений по Figma находится в
[REPORT-ETAP-6.md](REPORT-ETAP-6.md).

Так страницу проще читать: у шапки и первого блока свои HTML и SCSS файлы.

## Как выводится название компании

В `navbar.component.ts` есть свойство:

```ts
companyName = 'РУМТИБЕТ';
```

В `navbar.component.html` оно выводится так:

```html
{{ companyName }}
```

Двойные фигурные скобки — это интерполяция Angular. Angular берёт значение свойства из `NavbarComponent` и показывает его в шаблоне. Чтобы поменять название, достаточно изменить строку в `companyName`.

## Где находятся стили

`navbar.component.scss` отвечает за шапку, а `hero.component.scss` — за первый блок. Общие простые настройки страницы находятся в `src/styles.scss`.

Фоновая фотография макета подключена из `public/images/hero.png`. Браузер загружает файлы из папки `public` по пути от корня сайта, поэтому в стиле указан путь `/images/hero.png`.

Фотографии остальных секций находятся в `public/images`, иконки — в `public/icons`,
шрифты — в `public/fonts`. Шрифты подключаются через `@font-face` в `src/styles.scss`.
Текст страницы набран Nunito Sans, название компании — Next Art.

У первого экрана высота 985 px, общий контейнер — 1180 px. Заголовок выровнен по левому краю.
У полей прозрачный фон, поэтому через них видно фотографию, как в Figma.

Дата вводится стандартным `input type="date"`. Пока поле пустое, поверх него показана
подпись «Дата похода». Атрибут `required` делает пустое поле невалидным; когда дата выбрана,
CSS-селектор `input:valid + .hero__date-label` скрывает подпись. JavaScript для этого не нужен.

## Как открыть страницу

В папке проекта запусти:

```bash
npm start -- --host 0.0.0.0
```

Затем открой `http://localhost:4200`.

Поля выбора и кнопка сейчас показывают макет. Кнопка пока не запускает поиск.
